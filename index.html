Data statement. All 1,400 rows per run are generated in your browser from a seeded pseudo-random generator. There is no patient data, no student records, no shelter guest data, and no real-world pilot. This project has not been deployed in any clinic, school, or shelter.

Limits. Equal opportunity lifts underserved-group true positives toward the better training operating point, but it can change overall recall and widen a secondary gap such as selection rate. Every mitigation's recall and secondary-gap changes are shown in the trade-off banner, so no cost is hidden. Removing a proxy does not remove bias from every other correlated feature. Calibration is fitted only on training rows and reported on held-out rows. Small subgroups make any error rate noisy.
